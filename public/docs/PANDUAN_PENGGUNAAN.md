# Panduan penggunaan (dipecah)

Panduan ini sudah dipecah menjadi dua agar lebih mudah dibaca:

- **PANDUAN_PENGGUNA.md**: untuk umum, petugas, ahli gizi, dan guru (memantau, akun, asisten AI, Telegram, keselamatan).
- **PANDUAN_ADMIN.md**: untuk admin (akun, laporan, perangkat, Telegram & notifikasi otomatis, pengaturan).
- **PANDUAN_SELESAIKAN.md**: langkah awam menyelesaikan pemasangan dari awal sampai siap.

Semua bisa dibaca di website (bagian Bantuan) atau di panel admin (menu Panduan).
